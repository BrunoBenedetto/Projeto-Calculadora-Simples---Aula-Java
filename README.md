# 🧮 Calculadora em Java
---

# 📚 Sobre o Projeto

Este projeto consiste em uma calculadora simples desenvolvida em Java utilizando a biblioteca `JOptionPane` para interação gráfica com o usuário.

A aplicação permite realizar operações matemáticas básicas de forma simples e intuitiva através de caixas de diálogo.

---

# ⚙️ Funcionalidades

✅ Soma  
✅ Subtração  
✅ Multiplicação  
✅ Divisão  
✅ Interface gráfica com `JOptionPane`  
✅ Validação para divisão por zero  
✅ Execução contínua em loop  

---

# 💻 Tecnologias Utilizadas

- Java
- JOptionPane
- IntelliJ IDEA

---

# 🧠 Conceitos Praticados

- Estruturas condicionais (`switch`)
- Estruturas de repetição (`for`)
- Entrada de dados
- Conversão de tipos
- Operações matemáticas
- Interface gráfica simples
- Tratamento básico de erros

---

# ▶️ Como Funciona

1. O usuário informa o primeiro número
2. Escolhe a operação matemática
3. Informa o segundo número
4. O sistema calcula o resultado
5. O resultado é exibido em uma janela
6. O programa continua executando em loop

---

# 📂 Estrutura do Projeto

```bash
📦 src
 ┗ 📂 program

```

---

# 🖼️ Operações Disponíveis

```text
+  → Soma
-  → Subtração
*  → Multiplicação
/  → Divisão
```

---

# ⚠️ Observações

- O programa utiliza `Locale.US` para padronizar números decimais.
- Em caso de divisão por zero, uma mensagem de aviso é exibida.
- O sistema permanece em execução continuamente até ser fechado manualmente.
